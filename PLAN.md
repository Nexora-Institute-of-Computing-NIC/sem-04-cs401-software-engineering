# CS401 — Software Engineering — PLAN

**Semester:** 4 · **Credits:** 4 · **Level:** Intermediate-Advanced
**Theory:** 45 hrs · **Lab:** 30 hrs · **Tools:** Git, Jira/Trello, GitHub Actions, JUnit, Figma

## Syllabus

### Unit 1 — Software Engineering Foundations (9 lectures)
1. What software engineering is — and why it exists
2. The software crisis and its lessons
3. Software quality attributes — correctness, reliability, usability, maintainability
4. Software development life cycle (SDLC) overview
5. Process models — waterfall, iterative, spiral
6. Agile and Scrum — values, roles, ceremonies
7. Kanban and continuous flow
8. Lean software development
9. Choosing a process — context matters

### Unit 2 — Requirements Engineering (9 lectures)
1. Functional vs non-functional requirements
2. Eliciting requirements — interviews, workshops, observation
3. User stories and acceptance criteria
4. Use cases and scenarios
5. Requirements specification documents (SRS)
6. Requirements prioritisation — MoSCoW, Kano
7. Requirements traceability
8. Requirements change management
9. Common requirements failures — and how to avoid them

### Unit 3 — Software Design (9 lectures)
1. Design principles — modularity, abstraction, information hiding
2. Coupling and cohesion
3. SOLID principles — S, O, L, I, D
4. Architectural styles — layered, MVC, microservices, event-driven
5. UML — class diagrams, sequence diagrams, state diagrams
6. Design patterns — creational (singleton, factory, builder)
7. Design patterns — structural (adapter, decorator, facade)
8. Design patterns — behavioural (observer, strategy, command)
9. Documenting design decisions — ADRs

### Unit 4 — Construction, Testing, and Quality (9 lectures)
1. Coding standards and code review
2. Version control workflows — GitFlow, trunk-based
3. Unit testing — JUnit and pytest
4. Test-driven development (TDD)
5. Behaviour-driven development (BDD)
6. Integration testing and mocking
7. System and acceptance testing
8. Static analysis and linting
9. Code coverage — what it does and does not tell you

### Unit 5 — Project Management and Delivery (9 lectures)
1. Estimation — story points, planning poker, COCOMO
2. Scheduling — Gantt charts, critical path
3. Risk management — identify, assess, mitigate
4. Configuration management
5. CI/CD pipelines with GitHub Actions
6. Release management and semantic versioning
7. DevOps culture and practices
8. Technical debt — tracking and paying it down
9. Postmortems and continuous improvement

## Practical Labs (18)

1. Set up Git, GitHub, and a project board
2. Write user stories with acceptance criteria
3. Build a use case diagram and one detailed use case
4. Write a lightweight SRS for a small project
5. Draw a class diagram for a domain model
6. Draw a sequence diagram for a key workflow
7. Refactor a God class using SOLID principles
8. Implement a design pattern — singleton + factory
9. Write unit tests with JUnit for a small module
10. TDD kata — Roman numerals or FizzBuzz
11. Set up a CI pipeline with GitHub Actions
12. Configure code coverage reporting
13. Set up a code review workflow — branch protection + PR template
14. Create an ADR documenting an architectural decision
15. Estimate a backlog with story points
16. Build a Gantt chart for a 6-week project
17. Perform a postmortem on a simulated incident
18. Create a release — tag, changelog, deploy

## Assignments

1. Process comparison — analyse three methodologies on one project
2. Requirements document — SRS for a medium project
3. Design document — architecture and patterns for the project
4. Testing report — unit + integration + coverage for one module
5. Final project — full software engineering lifecycle deliverable
